# Document Fixture

`simple.doc` is the Word 97 sample from Apache POI's test data:

https://github.com/apache/poi/blob/trunk/test-data/document/simple.doc

Apache POI distributes its test data under the Apache License 2.0:

https://github.com/apache/poi/blob/trunk/legal/LICENSE

Copies of the license and notice are included in `Apache-POI-LICENSE.txt` and `Apache-POI-NOTICE.txt`.

The sample is used to verify genuine legacy binary DOC import without requiring Microsoft Word.
